### Config decisions worth knowing

- **Two `useExhaustiveDependencies` reports are suppressed, not fixed.**
  `text` in `useTypewriter` and `items`/`locale` in `ExperienceCarousel` are
  intentional re-run triggers, not values read in the effect body. Removing them
  as Biome suggests would break the reset and the title refit. Each suppression
  carries a written reason.
- **`css.parser.tailwindDirectives: true`** was required: Biome's CSS parser rejects
  Tailwind v4's `@theme` and `@custom-variant` without it, which made `npm run lint`
  fail on a pre-existing file.
- **Formatting was normalized to 2-space indentation.** The repository had drifted
  between tabs and spaces and no formatter had ever run.
- **`useSortedClasses` is a nursery rule.** It was enabled for parity with the
  removed `prettier-plugin-tailwindcss`. Class attribute order does not affect
  Tailwind output, since utilities are ordered in the generated stylesheet.
